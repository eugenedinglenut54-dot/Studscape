## ⚠️ Important Installation Note (Windows "Smart"Screen)

When running the executable, you may encounter a **"Windows Protected your PC"** (SmartScreen) prompt. This is a standard **false-positive**.

### Why does this happen?
* **Early Development:** The game is in its early stages and does not yet have a registered digital certificate or signature.
* **Cost Constraints:** Code-signing certificates are highly expensive for independent developers, and the project currently does not have the budget for one.

### How to run the game:
1. Click on **"More info"** inside the Windows prompt.
2. Click the **"Run anyway"** button that appears.
